# HYANS Mission Control — Read Me First

This directory is the governing handoff for consolidating HYANS, NORKO, Meridian, WMG, maritime intelligence, curriculum, stewardship, and client-program work into one durable operating system.

## Immediate instruction to Claude Code

Read every file in this directory in numeric order. Treat `01_GOVERNING_CHARTER.md` as the controlling specification.

Then:

1. Audit the current repository and approved local workspace.
2. Do not delete or overwrite source material.
3. Create an inventory of repositories, folders, applications, documents, datasets, media, prompts, and unfinished deliverables.
4. Propose the minimum safe migration plan.
5. Create the canonical folder structure.
6. Generate the initial backlog.
7. Begin executing Priority 0 tasks.
8. Record every decision, assumption, source, and unresolved conflict.
9. Commit work in small, reversible increments.
10. Stop only at an explicit approval gate, destructive action, credential requirement, legal/compliance decision, financial commitment, production deployment, or unresolved factual conflict.

## Immediate instruction to Hermes

Hermes is the local execution runner. It may index, copy, transform, validate, render, package, test, and report. It must not silently redefine strategy or overwrite canonical sources.

## Source-of-truth hierarchy

1. Approved client instructions and executed agreements
2. Verified authoritative records and primary sources
3. `knowledge/DECISIONS.md`
4. `knowledge/KNOWN_FACTS.md`
5. Approved project briefs and specifications
6. Working notes and model outputs
7. Chat history

Chat history is reference material, not canonical memory.
